# padamdahal.github.io

Personal guides hub for everyday digital tasks in Nepal.

- Homepage lists practical guides and links to free tools at [pbd.com.np](https://pbd.com.np/).
- First guide: [How to convert BS ↔ AD dates for official forms](guides/bs-ad-for-forms.html).

## Deploy

This is a plain static site. Push to the `master` branch of the `padamdahal/padamdahal.github.io` repository. GitHub Pages will serve it at https://padamdahal.github.io/.

## Search Console

Add `https://padamdahal.github.io/` as a URL-prefix property in the same Google Search Console account used for pbd.com.np. Submit the homepage and the guide URL for indexing after the first deploy.

## Content rules (keep)

- Only useful, non-thin guides.
- Natural links to pbd.com.np tools where they genuinely help the reader.
- No link-farm pages or doorway content.
