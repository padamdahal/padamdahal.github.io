Interactive Nepali Calendar (BS) — How to Use & Embed

Practical guide · Updated November 2026

The Interactive Nepali Calendar on pbd.com.np/tools/nepali-calendar is a free, client-side Bikram Sambat (BS) month view. You can browse any month, click a day to copy its Gregorian (AD) ISO date, or drag a day cell onto a form field to fill it automatically. After the first visit the page and library work fully offline.

This guide covers everyday use and how developers can embed the same calendar on their own sites so click-to-copy and drag-to-fill work on local forms.

What the calendar does

  • Shows a full Bikram Sambat month grid with optional AD dates.
  • Click any day (or focus it and press Enter) → copies the Gregorian ISO date (yyyy-mm-dd) to the clipboard.
  • Drag a day cell and drop it on any <input> or <textarea> on the same page → the field receives the ISO date (works on readonly fields by default).
  • Language toggle (Nepali / English), light/dark/auto theme, and Kathmandu timezone support.
  • API helpers for conversion: NepaliCalendar.toAD(), NepaliCalendar.toBS(), NepaliCalendar.today().

Everyday usage

  1. Open the calendar page and navigate to the month you need.
  2. Click a day to copy the AD date — paste it into bank forms, visa applications, spreadsheets, or chat.
  3. If you are filling a form on the same page (or have embedded the calendar), drag the day cell directly onto the date field.
  4. Use the language toggle when you want Devanagari month and day labels.
Tip Keep the calendar tab open while filling multiple forms. Click-to-copy is faster than switching between converter pages for every single date.

Supported range & accuracy

The calendar table covers BS 2000–2090 (roughly AD 1943–2034). Years through BS 2083 are verified against common sources used in Nepal. Later years are marked provisional. For critical legal or financial documents, always double-check the final date against the calendar your office or bank uses.

How to embed the calendar on your own website

The library is a single JavaScript file. Once loaded, click-to-copy and drag-to-fill work for every input on that page. You can mount a full interactive calendar or let the script auto-mount from a data attribute.

1. Full interactive calendar (recommended)

Include the script once, place a container, then call NepaliCalendar.mount().

<!-- 1. Include the library (once per page) -->
<script src="https://pbd.com.np/tools/nepali-calendar/nepali-calendar.js"></script>

<!-- 2. Place a container -->
<div id="my-calendar"></div>

<!-- 3. Mount it -->
<script>
  NepaliCalendar.mount('#my-calendar', {
    lang: 'ne',          // 'ne' or 'en'
    theme: 'light',      // 'light' | 'dark' | 'auto'
    timeZone: 'Asia/Kathmandu',
    showAD: true,
    langToggle: true
  });
</script>

After the script loads, any day cell can be dragged onto a normal input or textarea on the same page. The field receives the ISO date.

2. Zero-JavaScript auto-mount

If you prefer not to write your own script tag for mounting:

<div data-nepali-calendar
     data-lang="ne"
     data-theme="auto"
     data-time-zone="Asia/Kathmandu"></div>
<script src="https://pbd.com.np/tools/nepali-calendar/nepali-calendar.js"></script>

Useful API helpers

NepaliCalendar.toAD(2082, 7, 16);   // → "2025-11-02"
NepaliCalendar.toBS("2025-11-02");  // → { year: 2082, month: 7, day: 16 }
NepaliCalendar.today("Asia/Kathmandu");
